### 🌐 Mi Portafolio Web Interactivo

Este repositorio incluye una aplicación web interactiva desarrollada con **React, Vite, Tailwind CSS y GSAP** para una experiencia visual envolvente con animaciones fluidas.

- 🖥️ **Para ejecutarlo localmente**:
  ```bash
  cd portfolio
  npm install
  npm run dev
  ```
- 📦 **Construcción para producción**:
  ```bash
  npm run build
  ```
